# kmeans-clustering
 MMA/MMAB/MMAI 869 2023: Individual Assignment

## Overview
This repository contains the individual assignment for MMA/MMAB/MMAI 869 (2023), focusing on practical applications of machine learning techniques including clustering, association rules, classification, and cost-benefit analysis.

## Assignment Structure
The assignment consists of four main questions:

### Question 1: Customer Persona Clustering
- Clustering analysis of customer data to identify distinct personas
- Implementation of multiple clustering algorithms
- Cluster interpretation and business insights

### Question 2: Association Rules Analysis
- Thought experiment on market basket analysis
- Analysis of support, confidence, and interestingness of rules
- Real-world application in grocery retail

### Question 3: Credit Risk Classification
- End-to-end machine learning pipeline
- Feature engineering and selection
- Hyperparameter tuning
- Model evaluation and validation

### Question 4: Predictive Maintenance Cost Analysis
- Cost-benefit analysis of ML models
- Comparison of Random Forest vs RNN models
- Business decision-making based on model performance
